# 德州扑克练手桌（单机 · 绿色娱乐）

面向普通玩家的 **离线单机** 无限注德州扑克练习桌。  
**无联网对战、无广告、无内购、非真钱**——桌上只有练习筹码。朋友可以打开同一份页面，但每人是各自的单机进度，互不影响。

## 在线打开（GitHub Pages）

手机或电脑浏览器直接打开：

**https://jackzhangisme4real-collab.github.io/texas-holdem-practice/**

打开即可单机练手，含右侧 GTO 练手助手。进度写在这台设备浏览器的 localStorage 里。这不是联机牌局。

## 怎么打开（本机）

1. 进入文件夹（或解压 zip）。
2. 用浏览器打开 `index.html`。
3. 若刚覆盖了旧文件：**强制刷新**（Windows：`Ctrl+F5`；手机浏览器可清缓存或关页再开）。

可选自检：

```bash
node js/test-evaluator.js
```

## 怎么分享给朋友（静态站 · 手机也能开）

本项目是**纯静态文件**（HTML/CSS/JS），不需要服务器账号、不需要安装 App。任选一种即可：

### 方式 A：发 zip（最简单）

1. 把整个 `texas-holdem-practice` 文件夹打成 zip（仓库里已有 `texas-holdem-practice.zip` 时可直接发）。
2. 朋友解压后，用手机/电脑浏览器打开里面的 `index.html`。
3. 注意：部分手机系统直接点本地 html 可能受限；若打不开，改用方式 B/C。

### 方式 B：局域网临时托管（推荐给身边朋友）

在电脑项目目录执行（需已安装 Python）：

```bash
# Python 3
python -m http.server 8080
```

电脑与手机连同一 Wi‑Fi，手机浏览器访问：

`http://电脑的局域网IP:8080/`

（Windows 可在 `ipconfig` 里看 IPv4 地址。）

### 方式 C：丢到任意静态托管

把文件夹上传到 GitHub Pages / Cloudflare Pages / Netlify / 对象存储静态网站等，把生成的 **https 链接**发给朋友。  
用手机浏览器打开链接即可练；**仍然是每人自己的 localStorage，不是联机牌局。**

### 重要说明

- **不是线上多人牌局**，不能坐同一桌对打。
- 进度存在**该设备浏览器的 localStorage**；换浏览器/清站点数据会丢进度。
- 练习筹码与真钱无关；打光后只能按界面「重开 / 补充筹码 / 选桌」。

## 本机进度与选桌

- 自动保存：你的**练习筹码**、当前牌桌档位、主题/音效/难度、会话统计。
- 入门桌：每人起步 **1000**，盲注 **5/10**。
- 筹码变多后，可点顶栏 **「选桌」** 升到进阶/中级/高额练习桌（更高盲注）。
- **筹码归零**后不能继续打牌，必须：重开入门桌（1000）、补充 1000，或去选桌。

## 视觉主题

顶栏可切换 **专业** / **Q萌**：只影响外观与发牌表现，不改规则/AI。

## GTO 练手助手（离线）

拿到底牌后，右侧「GTO 练手助手」会自动刷新（每条街道也会更新）：

1. **位置**：BTN/CO/MP/EP/SB/BB 与优劣说明（相对仍在手的人数）
2. **起手范围语境**：手牌落在哪些粗分桶、该位置常见开池宽度（教材粗估）
3. **胜率估算**：对随机对手 / 偏强继续范围的蒙特卡洛近似（标明「估计 · 非求解器」）
4. **轻量 GTO 倾向**：开池/防守/3-Bet 等教学向提示，**不宣称是求解器精确频率**

全程本地计算，不联网。

## 本版亮点

- 荷官/发牌鞋发牌：牌飞到座位背面朝下，行动时再拿起/翻开
- 街道进度、公共牌逐张翻开、广播式行动标注
- D / SB / BB 座位标记；剩余筹码与本街投入区分显示
- 彩色筹码、轻音效、起手提示与教学

## 操作

| 控件 | 作用 |
|------|------|
| FOLD / CHECK / CALL | 弃牌 / 过牌 / 跟注 |
| 1/2 · 3/4 · POT · 2× | 常用加注快捷 |
| BET / RAISE · ALL-IN | 下注或全下 |
| NEXT HAND | 下一手（筹码为 0 时不可用） |
| 选桌 | 切换盲注档位（需足够筹码） |
| 重开 | 按当前桌起始筹码重置 |

## 规则摘要

标准 NLHE：盲注 → 翻前/翻牌/转牌/河牌 → 弃牌或摊牌。支持基础边池。
